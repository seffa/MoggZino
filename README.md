гемплей:
Уровень — это зал с одной или несколькими азартными играми. Чтобы подняться на следующий уровень, нужно набрать порог депозита (для перехода на уровень два - 2000 очков, для перехода на уровень три кол-во очков пока не определено). Депозит на старте 100.
Если депозит падает до нуля —Игра заканчивается, необходимо воспользоваться кнопкой сброса. 
Кнопка сброса должна работать только если пользователь пришлет кружок/видео с извинениями за свой проигрыш.

Структура уровней
уровень 1 
Игры: кости, слоты
уровень 2 
Игры: рулетка, русская рулетка.
Порог входа: 2000 очков.
уровень 3 
Игры: слоты, блэкджек, апгрейдер
Порог входа: не определен

Наследование:
Игра, уровень
Полиморфизм:
У каждой игры своя логика
